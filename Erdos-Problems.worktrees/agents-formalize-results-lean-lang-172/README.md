# Finite Sums and Products - Lean 4 Formalization

A complete Lean 4 formalization of the finite sums and products theorem: **Every finite colouring  contains arbitrarily large finite sets whose distinct finite sums and distinct finite products all have one common colour.**of 

## Files

- `FiniteSumsProducts.lean` - Core definitions and main theorems
- `FiniteSumsProducts_Lemmas.lean` - Supporting lemmas and properties
- `FiniteSumsProducts_Proof.lean` - Proof strategies and deductions
- `FiniteSumsProducts_Examples.lean` - Usage examples and demonstrations

## Main Results

1. **main_theorem**: Every r-colouring contains arbitrarily large sets with monochromatic finite sums and products
2. **finite_sums_products_theorem** (FSP): The foundational theorem from Milliken-Taylor
3. **finite_bound_version**: Equivalent finite formulation

## Key Definitions

- `FS(A)` - Set of all nonempty sums of distinct elements from A
- `FP(A)` - Set of all nonempty products of distinct elements from A
- `Colouring(r)` - Function  to r coloursfrom 
- `Monochromatic` - Sets where all elements have the same colour

## Mathematical Foundation

The theorem is based on:
- **Milliken-Taylor Theorem** (finite Ramsey theory)
- **Bergelson-Hindman** paper on finite sums-products
- **Distinction from Hindman's conjecture**: This provides finite configurations, not a single infinite sequence
